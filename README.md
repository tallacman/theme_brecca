# Brecca Theme
Brecca is a refined, minimalist Concrete5 theme designed for beautiful one-page websites, yet flexible enough to support a full multi-page site when needed.

Originally created with electronic invitations in mind, especially weddings, Brecca brings a sense of elegance, simplicity, and visual drama to any event, portfolio, personal site, or occasion-led project.

Built to pair beautifully with full-screen imagery and overlay effects, Brecca is ideal for sites where atmosphere matters. Whether you are showcasing an event, telling a story, or creating a small but memorable web presence, the theme keeps the focus on your content against a striking visual backdrop.

## Key Features
A dedicated Brecca Nav template neatly centers up to six page links, creating a balanced, polished look.

The site name is displayed prominently as an H1 and can be styled with a choice of eleven custom Google fonts. Eleven presets are included, primarily changing the site title font and giving you a clean starting point for further customization.

The theme offers full-page centered layouts, color customization through the theme panel, and both full-width and two-column content areas. A global area at the bottom of the page is perfect for social icons, registry links, or other supporting content.

Brecca also includes dedicated styling for the Image Slider and Social Links blocks, including a centered Social Links template that keeps icons neatly aligned in the middle of the page.

For event-focused sites, Brecca provides seventeen initial registry page icons, with room for more to be added as needed. A background image block is also included, making it easy to manage page backgrounds directly within the editing interface.

Behind the scenes, small JavaScript enhancements help preserve the theme’s polished appearance by reducing typographic widows and resizing the site name on smaller screens to avoid awkward line breaks.

Elegant, simple, and visually expressive, Brecca is an excellent choice for anyone who wants a clean Concrete5 theme that lets content shine against a memorable background.

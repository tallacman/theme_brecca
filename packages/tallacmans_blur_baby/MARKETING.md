# Tallacman's Blur Baby for Concrete CMS

**Tallacman's Blur Baby** displays a sharp featured image over a blurred copy of the same photo — a polished hero or spotlight effect without extra design work.

Built for **Concrete CMS 9**.

---

## Features

- **Dual-layer image** — Crisp foreground image with a blurred background duplicate
- **Adjustable blur** — Control blur amount, scale, and background height
- **Placement** — Align the blurred background top, center, or bottom
- **Width control** — Set foreground image width in pixels
- **Sticky live preview** — See the effect while editing

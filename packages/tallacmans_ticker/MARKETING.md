# Tallacman's Ticker for Concrete CMS

**Tallacman's Ticker** scrolls announcement text across your page — great for news, promotions, hours, or alerts.

Built for **Concrete CMS 9**.

---

## Features

- **Multi-line items** — One announcement per line, spaced as they scroll
- **Custom speed** — Control how long one full cycle takes (seconds)
- **Typography controls** — Font size in px, em, or rem; normal or bold weight
- **Color pickers** — Background and text colors
- **Text drop shadow** — Adjustable color, blur, and offset (set blur to 0 to disable)
- **Scroll direction** — Left or right
- **Accessible** — Respects `prefers-reduced-motion` and shows a static stacked list instead
- **Pause on hover** — Lets visitors read an item before it scrolls away
- **Item spacing** — Adjust the gap between phrases (0–240 px)
- **Continuous scroll** — Seamless looping is built in; items repeat with no gap or jump
